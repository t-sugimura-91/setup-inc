SET UP は、Google・Yahoo!・Metaなどの運用型広告を、戦略の設計から日々の調整、データ解析まで担当しています。コラムの記事は、すべて代表が企画し、内容を確認して公開しています。

経歴

  • 2019年〜2026年:事業会社で、年間数億円規模の運用型広告を担当。検索連動型広告(SEM)を主軸に、SNS広告やアドアフィリエイトを組み合わせ、獲得効率の改善と配信量の拡大に取り組む。
  • 2020年〜2026年:管理者として、メンバーの育成と運用フローの標準化を担当。
  • 2026年:個人事業として SET UP を開業。事業者・代理店の双方から、広告運用を請け負っている。

広告を運用する側と、予算を出す事業主側の両方の立場を経験していることが、記事の視点のもとになっています。

扱っている媒体・ツール

Google 広告、Yahoo!広告、Meta広告(Facebook・Instagram)、X広告、TikTok広告、LINE広告、Microsoft 広告、YouTube広告、アフィリエイト。計測まわりは、GA4、Google タグマネージャー、Looker Studio を扱っています。

コラムでは、これらの実務で関わる、広告のレポート、LPやサイトの置き場所、計測、仕事に使うツールなどを取り上げています。

記事の作り方

記事を書くときは、次の決まりを守っています。

  • 公式の情報で確認する。料金・仕様・特典は、各社の公式サイトや公式ヘルプで確認し、記事に出典と確認日を書きます。
  • 使っていないものを「使ってみた」と書かない。運営者が実際に使っていないサービスは、感想やレビューの形では書きません。公式に公開されている情報と、運営者の判断の基準を分けて書きます。
  • 口コミや評判を根拠にしない。「人気」「評判がいい」といった、確かめられない理由で薦めることはしません。
  • 「No.1」などの表現は、出典と一緒に紹介する。各社が掲げる順位や数値は、誰が調べたものかを添えて紹介し、運営者の言葉として断定しません。
  • 計算は計算と明記する。年額や総額など、公式の数字をもとに運営者が計算したものは、そのことを表や図の出典に書きます。
  • 情報が変わったら直す。料金や仕様の変更に気づいた場合は、記事を更新し、更新日を記載します。

広告(アフィリエイト)について

一部の記事では、アフィリエイト広告(A8.net)を利用しています。記事内のリンクから申し込みや購入があった場合、運営者が報酬を受け取ることがあります。

  • 広告を含む記事には、タイトルの近くに「PR」の表示と、その説明を入れています。
  • 紹介するサービスの選定と評価は、運営者の基準で行っています。報酬の額によって、評価や順番を変えることはしません。
  • 比較に必要なサービスは、広告の提携の有無にかかわらず取り上げます。提携していないサービスへのリンクは、公式サイトへの通常のリンクです。

誤りのご指摘・お問い合わせ

記事の内容に誤りや古い情報を見つけた場合は、お問い合わせフォームからお知らせください。確認のうえ、記事を修正します。個人情報の取り扱いは、プライバシーポリシーに記載しています。
